# 状态看板

状态看板把监控执行结果转换成适合连续观察的样本。它不是独立探测器：每个看板项都依赖一个已有监控及其执行记录。

## 数据来源

看板项可以选择：

- 监控的整体条件状态。
- 某一条条件规则的状态。
- 插件结果集中的字段。

整体条件和单条规则按布尔值展示。结果字段根据描述器或历史样本识别为 `boolean`、`number` 或 `text`。插件声明为结构化且支持路径的字段需要指定 JSON 路径。

## 显示规则

| 值类型 | 配置方式 |
| --- | --- |
| boolean | 成功/失败，可反转语义 |
| number | 精确值映射优先，否则按递增上界匹配数值区间 |
| text | 精确文本映射，未匹配时使用默认状态、标签和颜色 |

状态等级为 `success`、`warning` 或 `failure`，界面提供固定颜色预设。数值区间最后一段必须无上界，前面的上界必须严格递增。

每个看板项显示 20 到 200 次执行，默认 60 次。样本来自监控记录保留范围；清理或手动删除记录会缩短历史。

## 趋势规则

趋势规则在新执行记录写入时计算，并只在规则从未触发变为触发、或从触发变为恢复时发送通知。

| 类型 | 含义 |
| --- | --- |
| 连续异常 `consecutive` | 窗口内所有样本都是失败状态 |
| 异常次数 `count` | 窗口内失败样本达到指定最小次数 |
| 平均值 `average` | 数值窗口平均值与阈值比较 |
| 变化量 `delta` | 最后值减第一值，支持绝对值或百分比 |
| 斜率 `slope` | 对窗口数值按样本序号做线性回归斜率 |

平均值、变化量和斜率只适用于数值来源。窗口不完整、包含未知样本、包含非数值或百分比基线为零时，结果为 `unknown`，不会改变趋势活动状态。

## 创建建议

1. 先运行监控，确保已经有结构正确的结果。
2. 创建看板项并选择监控。
3. 选择整体条件、单条规则或结果字段。
4. 为数值配置完整区间；为文本配置常见精确值和默认状态。
5. 根据实际采样频率选择历史次数和趋势窗口。
6. 需要趋势事件时再选择通知渠道。

::: tip 窗口是执行次数
趋势 `window` 表示样本数量，不是时间长度。每 5 分钟执行一次时，12 个样本大致覆盖 1 小时；多 Cron 或手动执行会改变实际时间跨度。
:::

## 实时更新

管理界面通过 `/api/v1/status-board/ws` 接收新记录和样本变更。连接中断时页面会重新拉取完整快照，因此数据库中的看板配置与执行记录始终是事实来源。
