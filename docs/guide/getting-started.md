# 快速开始

本页从源码启动一个本地 Meerkit，并创建第一个 HTTP 监控。开发环境会自动构建仓库中的 HTTP 与 TCP 插件。

## 环境要求

- Go 1.26
- Node.js 22 与 npm
- Make
- Git

## 启动开发环境

在仓库根目录执行：

```bash
make deps
make dev
```

`make deps` 安装根 Go 模块、`web/` 前端和 `docs/` 文档站点依赖。`make dev` 同时启动：

| 服务 | 地址 | 作用 |
| --- | --- | --- |
| Vite 前端 | `http://127.0.0.1:5173` | 管理界面和热更新 |
| Meerkit 后端 | `http://127.0.0.1:8080` | API、调度、存储与插件宿主 |

前端开发服务器会代理 `/api` 和 WebSocket 请求。按 `Ctrl+C` 会停止两个进程。

::: tip 只启动后端
`make dev-backend` 会在 `web/dist` 缺失时先构建一次生产前端，然后从 `http://127.0.0.1:8080` 提供嵌入式界面。
:::

## 初始化管理员

首次打开界面时，输入并确认管理员访问密钥。密钥至少 12 个字符，服务端使用 Argon2id 保存其哈希。成功后浏览器获得 HttpOnly 会话 Cookie；修改请求还需要会话返回的 CSRF Token。

忘记密钥时，停止正在运行的服务并对同一个数据库执行：

```bash
go run . --data-dir ./data admin reset-key \
  --key 'replace-with-a-new-access-key'
```

该命令会重置密钥并撤销全部现有会话。使用自定义配置文件或 MySQL 时，传入与服务相同的 `--config` 或数据库参数。

## 确认插件

打开“监控插件”。开发宿主应显示：

- `Meerkit HTTP`，模块类型 `http`
- `Meerkit TCP`，模块类型 `tcp`

开发源码插件不需要导入和签名。正式发布版会从可执行文件同级的 `plugins/` 目录引导官方包；其他包可以在此页面上传。

## 创建第一个监控

1. 打开“监控项”，选择创建监控。
2. 名称填写一个可识别的值，采集模块选择 `HTTP`。
3. 保留默认 Cron `*/5 * * * *`，或输入其他表达式并查看接下来三次执行时间。
4. `URL` 填写可访问的 HTTP/HTTPS 地址，按需调整请求方法、超时和响应解析。
5. 点击“测试调用”，先确认配置与网络访问有效。
6. 添加条件，例如 `HTTP 响应 · 状态码 equals 200`。
7. 选择站内通知或已配置的其他渠道，然后保存。

默认 Cron 表示每 5 分钟执行。调度器接受标准 5 段 Cron、可选秒字段和描述符；所有监控统一使用设置页中的调度时区。

## 查看结果

监控详情页提供：

- 每次执行的开始时间、耗时、成功状态和摘要。
- 插件定义的结构化结果集。
- 条件整体状态和逐条规则结果。
- `triggered`、`recovered` 或 `none` 事件。
- 每个通知渠道的待发送、已发送、跳过或错误状态。

手动执行与定时执行都会保存记录、更新条件状态并发送相应事件。创建表单中的“测试调用”只验证并执行模块，不会创建监控记录或发送条件通知。
